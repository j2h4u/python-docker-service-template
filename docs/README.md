# Documentation

This directory contains project documentation.

- `BEST_PRACTICES.md` contains reusable QA, runtime, and repository practices.
  It is intentionally useful in repositories created from this template.
- `meta/` contains maintainer documentation for this template repository
  itself, including `meta/ROADMAP.md`. GitHub templates copy it mechanically,
  but new projects should delete or rewrite it.

The root `README.md` is the short human-facing overview. The root `AGENTS.md`
is the compact operational contract for agents.
